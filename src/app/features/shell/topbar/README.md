# shell/topbar/

Top application bar: project badge + switcher, commit/dirty indicator, token meter (`token-meter.ts`) with its inspector dialog, health-check shield (badge = the graph-free pass's open issue count; recursion-cycle/self-trigger findings join when the health pane's run delivers), theme and action menus. The focus-mode toggle used to live here — it moved beside the entry's content field (v1.8.0).
