# shell/mobile-bottom-bar/

Phone-only bottom action bar (New entry, Search, Export, Batch edit, History) — the mobile answer to desktop toolbars; hidden on tablet/desktop breakpoints. Always docked while a phone session has a project: an open drawer lowers it to `backgrounded` via its `barState` input (scrim veil + inert content — the strip sits below the sidenav container, so it synthesizes the scrim look instead of inheriting it), and full-viewport CDK overlays simply cover it.

**Batch swap (Task 06)**: while the entries drawer is open with an active selection, `barState` reads `batch` and the five quick actions give way to the entry-list batch toolbar transplanted into the strip — same `div.batch-bar[role=toolbar]` DOM contract (select-all checkbox, `N selected`, tune / call_split / more_vert / close), centered, with a subtle `secondary-container` tonal top edge on the host (approved variant A2). The bar is presentational: it holds no selection state — `selectionCount` / `allShownSelected` / `someShownSelected` arrive as narrow inputs from the shell (mirrors of `EntryList`'s public signals), and both the toolbar and its menu only emit `batchAction`, which `App.runBatchBarAction` routes to the `EntryList` public methods. After `clear-selection` / `delete-selection` (which collapse the selection mid-tap), the shell re-focuses the entries pane.
