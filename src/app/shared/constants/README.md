# shared/constants/

App-wide constants: `breakpoints.ts` (handset/tablet breakpoints), `touch-targets.ts` (44px floor, 48px on phones), `github.ts` (repo links + icon), `brand-mark.ts` (the LoreStitch mark as an inline SVG literal registered with MatIconRegistry — same strategy as the GitHub icon), `search.ts` (200ms search debounce shared by the sidebar filter and the Search & Replace dialog).
